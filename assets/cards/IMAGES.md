# Card Image Assets

Place the three card images here with these exact filenames:

| File | Card |
|------|------|
| `moonchaser.jpg` | The Moonchaser (XVIII) |
| `alchemist.jpg` | The Alchemist (XIII) |
| `transformation.jpg` | The Transformation (XIII) |

`tarot-launch.html` references these paths. The page degrades gracefully with
styled CSS placeholders if the images are absent.
